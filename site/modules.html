Module map

Twenty-three files, one job each. The dependency graph is acyclic: container codecs receive the item dispatcher as a parameter instead of importing it, and no codec depends on the allocation policy.

On this page

Layers

Each module imports only from its own layer or the layers below. The modules highlighted in blue are the ones the tour spends most time in. Select a module to open its source.

That last point is visible in the signatures. The dispatcher types are declared next to the state they act on:
